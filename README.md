# Never Ending Netflix

Manifest V3 migration of Chrome Web Store item `hdadmgabliibighlbejhlglfjgplfmhb`.

The MV2 persistent background page, remote popup font, bundled jQuery, Modernizr, Gumby, and old Fuse bundle have been removed. WXT now generates Chrome, Edge, Firefox, and Safari MV3 packages from typed content and popup entrypoints while preserving the existing locale catalog and genre data.

Run `npm install`, then `npm run build`.
